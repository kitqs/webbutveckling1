# Övning 2 - HTML: märk upp en spelhistoria

Kopiera hela den här mappen till rotmappen i det publika GitHub-repository som du skapade i övning 1. Skapa inte ett nytt repository inne i övningsmappen.

Skapa `index.html` här. Behåll `images` bredvid `index.html`. Bilderna är nyskapade SVG-filer i formatet 1200 x 675 (16:9).

Följ den fullständiga elevinstruktionen i Teams. Gör minst tre meningsfulla commits, pusha arbetet och kontrollera filerna på GitHub innan du lämnar repo-länken i Teams.
